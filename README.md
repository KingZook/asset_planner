My personal policy on AI

Following in the footsteps of institutions, I will (attempt to) always acknowledge both AI generated code and modified snippets of code.
A large part of the goal of this project is to learn and **understand** the technology behind it, and to write **better** code than the code I wrote yesterday. For this reason, I believe that the use of AI is, in general, to my disadvantage, unless I have already gained the fundamental exposure necessary to confidently understand the outputs, and the underlying workings of the generated snippet.
