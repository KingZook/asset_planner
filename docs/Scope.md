### Scope and high level requirements

## Version 1 requirements

# Functional

View financial transactions from primary bank via API

Add transactions manually to a database

Have a database of transactions associated with a user account



# Non-functional

Deployment compatible with Personal Machine, Azure, AWS or google cloud services 

Database service compatible with home nas - i.e. MySql version xxxx

Compatible with a managed database service

Data encryption on database per user.

Educational requirement to implement the backend in rust

Educational requirement to use docker and kubernettes 

Build and test for PR's as a project requirement
